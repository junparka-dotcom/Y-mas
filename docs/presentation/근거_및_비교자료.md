## 2. 의료 문제 규모

### AHRQ PSNet

- 미국 병원에서 연간 약 **70만~100만 명**이 낙상을 겪는 것으로 추정한다.
- 역학 연구의 병원 낙상률은 **병상일수 1,000일당 3~5건** 수준이다.
- 병원 낙상의 **3분의 1 이상**이 손상으로 이어질 수 있다고 설명한다.
- 출처: [AHRQ PSNet — Falls](https://psnet.ahrq.gov/primer/falls)

## 3. 유사 서비스·기술

### 3.1 베드이탈/사이드레일 센서 연구

- 사이드레일 통합 센서의 예비 평가에서 민감도 **96.0%**, 특이도 **95.5% 이상**이 보고됐다.
- 이는 Y-mas와 데이터, 과제, 환경이 다르므로 100% 대 96%로 직접 순위를 매길 수 없다.
- 출처: [PubMed — Development and alarm threshold evaluation of a side rail integrated sensor technology](https://pubmed.ncbi.nlm.nih.gov/20083427/)

### 3.2 Vayyar Care

- 4D imaging radar 기반 비접촉 상용 서비스다.
- 공식 자료는 암실·수증기 환경 동작, 카메라 미사용, 센서 1대 최대 **16m²** 모니터링을 설명한다.
- 공식 공개 페이지에서 제품 정확도나 종단 지연의 명확한 수치는 확인하지 못했다.
- 출처: [Vayyar Care — How it works](https://vayyar.com/care-pages/how/)

### 3.3 Nobi Smart Lights

- 조명에 영상 기반 낙상 감지, 호출, 야간 조명, 분석 기능을 통합한 상용 서비스다.
- Lancaster University가 소개한 독립 평가는 약 **800개 조명, 79개 요양시설, 2년** 규모였다.
- 해당 평가에서 전체 낙상 **32% 감소**, 평균 대응 시간 **11분→2.99분**, 구급차 출동 **23% 감소**가 보고됐다.
- Nobi 공식 사이트는 전 세계 **330개 이상 커뮤니티**, **15,000개 이상 조명**, 낙상 후 평균 도움 도착 **4분 미만**을 제시한다.
- 출처: [Lancaster University — Nobi evaluation](https://www.lancaster.ac.uk/news/-lancashire-and-south-cumbria-care-home-falls-cut-by-a-third-with-use-of-smart-lights), [Nobi 공식 사이트](https://www.nobi.life/)

### 3.4 4D 레이더 연구 참고

- 2025년 4D imaging radar+CNN 연구는 자세 분류 정확도 **98.66%**, 낙상 감지 **95%**를 보고했다.
- 상용 Vayyar 성능 수치가 아니라 별도의 학술 연구다. Y-mas와 직접 비교할 수 없다.
- 출처: [PubMed — Non-Contact Fall Detection System Using 4D Imaging Radar](https://pubmed.ncbi.nlm.nih.gov/40968984/)

## 4. 경쟁 비교 결론

### 현재 직접 말할 수 있는 우위

1. **같은 Y-mas 평가 조건에서 v17보다 v21이 개선됨**
   - 동적 낙상 recall: 97.62%→100%, **+2.38%p**
   - 전체 FP clips: 79→70, **−11.4%**
2. **구조적 차별점**
   - 로드셀 하중·COG 물리 신호와 IR/Depth skeleton AI의 결합
   - Normal/Risk/Fall 3단계 판정
   - 모델 확률 + zone 이탈 + 몸통 기울기의 복합 판정
   - 원본 RGB 대신 IR와 skeleton 중심 처리

### 아직 말할 수 없는 우위

- Nobi보다 실제 낙상을 더 많이 줄인다.
- Vayyar보다 실제 병실 정확도가 높다.
- 시간당 오경보가 상용 제품보다 적다.
- 병원 운영비를 몇 % 절감한다.

이 항목들은 실병실 전향 검증, patient-day 기준 지표, 경쟁 제품과 동일 프로토콜 비교가 필요하다.

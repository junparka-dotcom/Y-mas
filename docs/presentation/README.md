## slides.html 사용법
- 브라우저로 `slides.html`을 열면 됩니다. (별도 설치/서버 불필요)
- 조작: `→`/`Space` 다음, `←` 이전, `F` 전체화면, `P` 인쇄(→ PDF 저장), 화면 좌/우 클릭으로도 이동.
- **자체 완결형**: CSS·JS가 파일 안에 내장되어 CDN 없이도 동작. 웹폰트만 인터넷에서 불러오며(현장 인터넷 사용), 실패 시 시스템 폰트로 자동 폴백.
- **S11(시연 영상)은 플레이스홀더**: 영상 완성 후 해당 슬라이드의 `.videobox`를 `<video src=...>`로 교체.

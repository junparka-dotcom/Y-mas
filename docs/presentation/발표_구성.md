# Y-mas 경진대회 발표 구성

> 의료 Physical AI 경진대회 — 발표 10분 + 질의응답 5분
> 시연 방식: 실제 실행 영상. 영상 파일은 추후 삽입하며 현재 슬라이드는 플레이스홀더로 유지.

## 발표 논리

**의료 문제 → 기존 해법과 빈틈 → Y-mas 구조 → 데이터 → 모델 → 워크플로우 → 검증 → 경쟁 비교 → 시연 → 발전 가능성**

성능 수치는 반드시 평가 범위를 함께 말한다. 특히 `recall 1.000`은 실제 병원 성능이 아니라 Kinect 계열 Holdout의 NTU A043 동적 낙상 84 clips 결과다.

## 장표별 발표 핵심 문장

### S1. 타이틀
> “Y-mas는 낙상이 일어난 뒤 알리는 시스템에서, 위험 단계에 미리 개입하는 병상 엣지 AI로의 전환을 목표로 합니다.”

### S2. 의료 문제
> “AHRQ에 따르면 미국 병원에서 연간 70만~100만 명이 낙상을 겪고, 3분의 1 이상이 손상으로 이어집니다. 간호사가 개입할 시간을 확보하려면 사후 감지만으로는 부족합니다.”

### S3. 기존 해법과 빈틈
> “압력 센서, 4D 레이더, AI 조명 같은 해법이 이미 있습니다. Nobi는 79개 시설 평가에서 낙상을 32% 줄였습니다. 그러나 센서별로 자세 해석, 사전 경고, 비용과 개인정보에 서로 다른 빈틈이 있습니다.”

### S4. Y-mas 구조
> “로드셀 4개가 하중과 무게중심 변화를 보고, IR/Depth AI가 자세와 움직임을 다시 확인합니다. 빠른 물리 신호와 정밀한 자세 AI를 결합해 한 센서의 약점을 다른 센서로 보완합니다.”

### S5. 데이터
> “Kinect V2 계열 NTU와 ETRI 전체 34,681 clips를 사용했고, 실제 Train은 18,771 clips입니다. 같은 사람이 학습과 평가에 섞이지 않도록 피험자 단위로 분리했습니다.”

> “동적 낙상은 NTU 947 clips, Risk는 NTU에만 있다는 한계가 있습니다. 그래서 공개데이터 결과를 임상 성능으로 확대해서 말하지 않습니다.”

### S6. 모델·알고리즘
> “64프레임, 25관절을 Joint·Bone·Velocity 3개 흐름으로 만들고, ST-GCN이 관절의 공간 관계와 시간 변화를 학습합니다. 여기에 머리 하강속도와 몸통 기울기 같은 물리 특징 10종을 결합합니다.”

### S7. 개발 워크플로우
> “Validation에서 precision 0.95 이상인 임계값만 남긴 뒤 recall을 최대화하고, Holdout에는 정한 임계값을 한 번 적용합니다. 학습과 추론 전처리를 동일하게 유지하는 것도 핵심 원칙입니다.”

### S8. 실시간 워크플로우
> “Femto W의 IR과 Depth로 3D 뼈대를 만들고 ST-GCN으로 분류합니다. 모델 확률 하나에만 의존하지 않고 zone 이탈과 몸통 기울기 45도를 결합해 안전장치를 둡니다.”

> “현재 Tier2 실시간 경로와 Tier3 웹 프로토타입은 구현됐습니다. Tier1 실물부터 v21, Tier3까지의 전체 E2E는 다음 통합 단계입니다.”

### S9. 정량 검증
> “같은 Holdout에서 v17 대비 v21은 동적 낙상 recall을 97.62%에서 100%로 2.38%p 높였고, false-positive clips는 79개에서 70개로 11.4% 줄였습니다.”

> “100%는 NTU A043 동적 낙상 84 clips에 한정된 수치이며, 실제 병실 정확도를 뜻하지 않습니다.”

### S10. 경쟁력 비교
> “Y-mas 100%와 베드센서 연구 96%는 서로 다른 실험이므로 4% 더 좋다고 말할 수 없습니다. 현재 직접 주장할 수 있는 우위는 같은 조건의 v17 대비 개선입니다.”

> “현재의 차별점은 하중 센서의 빠른 trigger, 자세 AI의 정밀 판정, 물리 규칙의 안전장치를 하나의 병상 워크플로우로 묶었다는 점입니다.”

### S11. 시연
> “현장 안전상 낙상 연기는 영상으로 대체했습니다. 영상은 실제 Jetson 실행 화면이며, IR skeleton과 확률 변화, Risk 사전 경고, Fall event 전송을 순서대로 보여드립니다.”

### S12. 발전 가능성
> “다음은 Femto W 실데이터 파인튜닝과 실물 E2E 검증입니다. 이후 같은 센서 위에 욕창 예방 자세 분류, 이상 호흡, 장기 부동 감지를 얹어 풀 베드 플랫폼으로 확장할 수 있습니다.”

## A. 발표 전 확인할 코드 문제

### 1. 물리 특징 입력 불일치 — 지적 타당 (버그 가능성 높음)

**현재 코드 (`edge/ymas_realtime_ir.py` 528행 부근):**
```python
seq_resampled = resample(seq_raw, T)
seq_norm, torso = normalize_seq(seq_resampled)   # 정규화 후 좌표
phys = physics_features(seq_resampled, FPS)      # ← 정규화 '전' 원좌표 사용
```

**버그로 의심되는 근거 (저장소 내 확인):**
- 학습 통계 `pmean[8] = 2.47` (spine_span 평균).
- `normalize_seq`는 몸통 길이로 나눠 정규화한다(`seq / torso`). 이 스케일에서 spine_span 2.47은 자연스럽다.
- 실시간에서 넣는 `seq_resampled`는 미터 단위 원좌표라, spine_span이 사람 키(1.5~1.8m)로 나와 학습 분포와 어긋난다.
- 따라서 **학습은 정규화 좌표, 추론은 원좌표**로 physics를 계산 중일 가능성이 높다. 전처리 불변식(인수인계 교훈 5) 위반.

**영향:**
- 높이·수평이동·span·속도 계열 특징이 학습 분포와 어긋난다.
- tilt 특징(인덱스 4, 5)은 각도(arccos)라 스케일과 무관 → 영향 적음.
- 실환경 정상 자세에서 P(Fall)이 0.75~0.80으로 튀는 현상의 유력한 원인 중 하나.

**확정하지 못하는 이유:**
- 학습 캐시를 만든 노트북 CELL 4/7 원본이 저장소에 없다(캐시는 `.gitignore` 제외).
- `physics_features`에 `seq_norm`을 넣었는지 `seq_resampled`를 넣었는지는 그 노트북을 직접 봐야 확정된다.

**조치 (멘토링에서 확인):**
1. 노트북 CELL 4/7에서 `physics_features(...)`의 인자가 정규화 후 좌표인지 확인.
2. 맞다면 528행을 `phys = physics_features(seq_norm, FPS)`로 수정.
3. 수정 후 정량 슬라이드의 P(Fall) 관련 수치와 임계값(TH) 재측정.
4. ⚠️ 저장소 코드는 아직 수정하지 않음.

### 2. 장비 모델과 발표 수치 불일치 — 지적 타당 (슬라이드에 이미 명시)

**확인 내용:**
- 정량 검증 슬라이드의 `84/84`, recall 100%는 **v21** 결과.
- 그러나 `edge/ymas_realtime_ir.py` 실배포 기본값은 여전히 v17.
  - `FALL_ONNX_PATH = "ymas_v17.onnx"`
  - `TH_FALL = 0.75` (주석에만 "v21 배포 시 0.77")
  - `PMEAN / PSTD`도 v17 값.
- 발표 수치(v21)와 실행 코드 기본값(v17)이 다름.

**조치:**
- v21 체크포인트를 실배포 경로에 반영할 때 ONNX 경로, `TH_FALL=0.77`, `PMEAN/PSTD`를 **반드시 v21 값으로 함께 교체**.
- 셋 중 하나만 바꾸면 조용히 틀린다.
- 시연 영상도 v21로 촬영해야 발표 수치와 일치.

### 3. 시연 2단계 오경보 위험 — 지적 타당 (리허설 필수)

**코드 근거:**
```python
pred_class = 2 if probs[2] >= TH_FALL else int(np.argmax(probs[:2]))
```
- 앉은 자세의 P(Fall)이 임계값(0.75/0.77) 근처면, "걸어 내려오기(정상 기상)" 동작에서 확률이 임계를 살짝 넘겨 오경보가 날 수 있다.
- 1번 버그가 있으면 앉은 자세 확률이 더 불안정해져 위험이 커진다.

**조치:**
- 시연 시나리오(Normal → Risk → Fall)를 리허설로 반복 재생해, 2단계(Risk → Fall 전환부)에서 조기 오경보가 없는지 확인.
- 필요하면 시연용으로 임계값·구간을 안정화.

| 항목 | 발표값 | 문서값 | 판정 |

| Tier 1 지연 | 200ms | 141~181ms | **적절.** 중앙값 필터 미적용 몬테카를로(1,000회) 기준의 보수적 값. "실물 측정값 아님" 명시도 정확. 실물·반복 측정 전까지 유지 |

# 전시 부스 포스터 — 의료 Physical AI 솔루션 경진대회

대회 제공 템플릿(전시 부스 포스터)에 맞춰 제작한 **Y-mas** 포스터입니다.

- **파일:** [`ymas_poster.html`](ymas_poster.html) — 자립형 단일 HTML (외부 리소스 없음)
- **규격:** 가로 **950 mm × 세로 1,200 mm** (대회 지정, 세로형)
- **템플릿:** Physical AI(보라) 양식 — 센서·엣지·하드웨어 융합 프로젝트에 해당
- **폰트:** Paperlogy(설치 시 자동 사용) → 없으면 Noto Sans KR / 맑은 고딕으로 대체
  - 대회 권장: 제목 36–42pt · 본문 26–32pt · 각주 20–24pt (본 포스터 반영)

## PDF / 이미지로 변환하는 법

### 방법 1 — 브라우저 인쇄 (가장 간단)
1. `ymas_poster.html`을 크롬에서 연다.
2. 인쇄(Ctrl/⌘+P) → 대상 "PDF로 저장".
3. 용지 크기를 **사용자 지정 950×1200 mm**(또는 가장 가까운 대형 규격)로, 여백 "없음", 배경 그래픽 "켬"으로 설정.

### 방법 2 — Chrome 헤드리스 CLI
```bash
google-chrome --headless --no-sandbox \
  --print-to-pdf=ymas_poster.pdf \
  --no-pdf-header-footer \
  ymas_poster.html
```

### 방법 3 — 고해상도 PNG (대형 출력용)
Playwright/Puppeteer 등으로 viewport를 비율(950:1200)에 맞춰 크게 잡고 `fullPage` 캡처.

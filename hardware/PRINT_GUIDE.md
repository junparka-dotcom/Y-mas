## 출력 전에 반드시 — 치수 검증

지금 STL은 **가정값으로 뽑혀 있습니다.**

```
wheel_d      = 60    // 바퀴 지름  ← 실측 필요
wheel_thk    = 22    // 바퀴 두께  ← 실측 필요
CRADLE_depth = 9     // V홈 깊이   ← 실물 테스트 필요
```

크래들 슬롯 폭은 `wheel_thk + 3`, 고임목 폭은 `wheel_thk + 2`로 바퀴 두께에 직접 묶여 있습니다. 실제 바퀴가 22mm가 아니면 **크래들과 고임목은 그대로 못 씁니다.** 캘리퍼스로 재고 `rail_spec.scad`를 고친 뒤 재생성하세요.

패드·브래킷·램프는 바퀴 치수와 무관하므로 지금 STL로 출력해도 됩니다.

## 재료 선택 — PLA를 쓰면 안 되는 부품이 있습니다

`rail_pad`와 `rail_bracket`은 **하중 경로에 직렬로 들어갑니다.**

```
바닥 → [rail_pad] → 로드셀 → [rail_bracket] → 레일 → 바퀴 → 침대
```

즉 침대 하중의 1/4(로드셀 정격 100kg 기준 최대 100kg)이 이 두 부품을 상시 통과합니다. 문제는 하중의 크기가 아니라 **지속 시간**입니다.

PLA는 상온에서도 **크리프(creep)** 가 일어납니다. 일정 하중을 며칠간 계속 받으면 소성 변형이 서서히 누적되는데, 이게 계측에 치명적인 이유는 파손 때문이 아닙니다. 부품이 천천히 눌리면 **로드셀 영점이 계속 밀립니다.** 낙상 감지는 COG의 미세한 이동을 보는 시스템인데, 센서 지지 구조가 스스로 변형하면 그 드리프트가 신호에 섞여 들어갑니다. 재영점을 아무리 돌려도 원인이 사라지지 않습니다.

> **이 프로젝트 결정:** 하중 경로 부품은 **PETG**로 출력합니다 (밤부랩 H2D). 세팅은 아래 "밤부랩 H2D + PETG 출력 세팅" 섹션 참고.

| 부품 | 권장 재료 | 이유 |
|---|---|---|
| `rail_pad`, `rail_bracket` | **PETG** (택: ABS/ASA), 인필 60%+, 벽 5겹 | 지속 하중 크리프 방지. 여유가 되면 알루미늄 절삭품이 가장 확실 |
| `wheel_cradle` | PETG 권장, 인필 40% | 바퀴 하중 + 굴림 마찰 |
| `wheel_chock` | PLA 가능, 인필 30% | 측면 걸림 역할, 지속 압축 없음 |
| `rail_ramp_seg*` | PLA 가능, 인필 10~15% | 진입 시 순간 하중만. **하중 경로와 분리된 부품** |

램프 인필을 낮게 잡아도 되는 근거는 설계 원칙에 있습니다 — 램프가 로드셀 지지 구조에 닿으면 하중이 두 경로로 갈라져 측정값이 왜곡됩니다. 그래서 램프는 애초에 **독립 부품**으로 설계됐고, 침대가 올라탄 뒤에는 하중을 전혀 받지 않습니다.

## 출력량 — 미리 알고 시작하세요

솔리드 부피 합계 약 **3,000 cm³**입니다. 인필과 벽을 감안한 실사용량은 대략 **1.2~1.5 kg** (PLA 기준 1.5 스풀).

그중 **램프 3종이 2,127 cm³로 전체의 71%** 를 차지합니다. 램프만 프린팅으로 해결하려면 며칠이 걸립니다.

현실적인 대안:
- 램프 인필 10% + 상하면 3겹으로 낮추기 (강도는 충분합니다)
- 램프를 **합판이나 각목으로 제작** — 15° 경사면만 만들면 되는 단순 형상이고, 정밀도가 전혀 필요 없는 부품입니다
- 시제품 단계라면 **레일 1개분만** 먼저 출력해 검증 (패드 2, 브래킷 2, 크래들 2, 고임목 4, 램프 1세트)

## 밤부랩 H2D + PETG 출력 세팅

로드셀 하중 경로(`rail_pad`, `rail_bracket`)는 **PETG로 출력**합니다. H2D 기준 세팅입니다.

### 왜 PETG인가 (재확인)

`rail_pad`와 `rail_bracket`은 침대 하중의 1/4(로드셀 CAS BCA-100L 정격 100kg)을 **상시** 통과시키는 하중 경로에 직렬로 들어갑니다. PLA는 상온에서도 지속 하중을 받으면 크리프(creep)로 서서히 눌리고, 그러면 로드셀 영점이 계속 밀려 낙상 감지 신호에 드리프트가 섞입니다. PETG는 크리프 저항이 PLA보다 크게 우수해 이 용도에 적합합니다. (여유가 되면 이 2종만 알루미늄 절삭품이 가장 확실합니다.)

### 필라멘트 준비

- **Bambu PETG-HF** 또는 동급 PETG 권장 (H2D 프로파일 안정적, 워핑 적음)
- PETG는 흡습에 민감 → 출력 전 건조 필수. AMS 건조 기능 사용 또는 65℃ 6~8h 사전 건조
- AMS에 물릴 경우 습도 표시 확인. 눅눅하면 표면 거칠고 층간 접착이 약해져 크리프 저항이 떨어집니다

### H2D 슬라이서 프로파일 (Bambu Studio)

하중 경로 부품(`rail_pad`, `rail_bracket`) 기준:

| 항목 | 값 | 근거 |
|---|---|---|
| 노즐 온도 | 250~260℃ | PETG 표준. 층간 접착 확보 위해 하한보다 살짝 높게 |
| 베드 온도 | 70~80℃ | PETG 밀착 |
| 벽(월) 수 | **5겹 (2mm)** | 하중 경로 강성 |
| 상/하면 | **5겹** | 압축면 강성 |
| 인필 | **60% 이상**, Grid 또는 Gyroid | 지속 하중 크리프 방지 |
| 층 높이 | 0.16~0.20mm | 얇을수록 층간 접착 면적↑ (크리프에 유리) |
| 출력 속도 | 표준의 70~80%로 하향 | PETG는 과속 시 층간 접착 저하 |
| 냉각 팬 | 30~50% (과냉각 금지) | PETG는 팬 세면 층 분리 → 하중 부품에 치명적 |
| 리트랙션 | PETG 프로파일 기본값(스트링 주의) | - |
| 브림 | 필요 시 사용 | 얇고 넓은 브래킷 밀착 |

> **주의:** PLA 감각으로 팬 100% + 고속으로 뽑으면 층간 접착이 약해져 크리프 저항이 무너집니다. PETG 하중 부품은 "느리게, 덜 식히고, 두껍게"가 원칙입니다.

### H2D 활용 노트

- H2D 베드는 **350×320mm**로 넓습니다. 배치 출력용 **plate STL을 미리 만들어 뒀습니다** → `hardware/plates/` 참고. 26개 부품이 3판으로 묶여 있어 출력 준비 시간을 줄일 수 있습니다:
  - `plate1_pads.stl` — rail_pad ×4
  - `plate2_bracket_cradle.stl` — bracket ×4 + cradle ×4
  - `plate3_chock_ramp.stl` — chock ×8 + ramp ×6 (부피 커서 시간 오래 걸림, 램프 인필 낮추기 권장)
  - Bambu Studio에서 열면 개별 오브젝트로 인식되어 재배치·개별 인필 설정 가능
- H2D의 듀얼 노즐/멀티컬러는 이 부품에선 불필요(단색·단일재질). 한 노즐로 배치하면 됩니다
- ASA도 크리프 저항 대안이나, H2D는 챔버 히터가 없어 워핑 관리가 까다롭습니다. **PETG가 H2D에서 가장 무난한 선택**입니다

## 출력 방향

| 부품 | 베드에 놓는 면 | 이유 |
|---|---|---|
| `rail_pad` | **지지 발이 아래로** 향하게(단상은 위) | 발 4점이 베드에 닿음. 적층 방향 ⊥ 압축 하중 → 층간 분리 최소. 발 밑에 브림 권장 |
| `rail_bracket` | 넓은 평면 | 위와 동일. 서포트 불필요 |
| `wheel_cradle` | 바닥면 | V홈이 위를 향함. 서포트 불필요 |
| `wheel_chock` | 넓은 바닥면 | 경사면이 위로. 서포트 불필요 |
| `rail_ramp_seg*` | 경사 반대쪽 평면 | 측벽이 오버행이 되지 않도록. **다웰 핀은 옆면으로 돌출** → 서포트 없이 출력되나 핀 처짐 시 브림/각도 조정 |

전 부품 서포트 없이 출력 가능한 형상입니다. 패드 지지 발(2.5mm)은 얇으니 첫 층 밀착에 유의하세요.

## 출력 후 체크리스트

- [ ] **패드 4점 지지 발이 평평한지** — 4개가 같은 평면에 닿아야 흔들림 없이 영점 안정. 첫 층 들뜸 있으면 사포로 정리
- [ ] 패드 하면 카운터보어(⌀11.5)에 M6 볼트 머리가 들어가는지 — 발 때문에 하면이 떠 있어 볼트 머리는 바닥에 안 닿음(정상)
- [ ] 브래킷 중앙 4홀(19×15 피치)이 로드셀 자유단 탭과 맞는지 (두께 8mm 맞는 M6 볼트 길이 확인)
- [ ] **로드셀 자유단이 확실히 떠 있는지** — 고정단만 단상에 물리고 나머지는 공중에 떠야 정상 측정됩니다. 여기가 닿으면 측정값이 통째로 죽습니다
- [ ] **램프 다웰 결합** — seg0↔seg1↔seg2 핀이 구멍에 들어가 세그먼트가 밀리지 않는지 (뻑뻑하면 구멍 리머로 살짝 확장)
- [ ] 크래들에 실제 바퀴를 굴려 넣어 앞바퀴 통과 + 뒷바퀴 안착이 동시에 되는지 (**바퀴 실측 후 `wheel_thk`/`wheel_d` 반영 필수** — 미반영 시 크래들 렌더가 assert로 막힘)
- [ ] T너트가 알루미늄 프로파일 슬롯에 맞는지 (30×60 프로파일 슬롯 규격 확인)
